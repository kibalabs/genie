How it works

        
From YAML to typed code in five stages

        
Each build runs the same pipeline. An invalid spec stops at the first stage that rejects it, so you never get half-generated code.

      

      

        

        

          
01

          
Syntactic check

          
The raw YAML is checked against a JSON Schema for names, patterns and value types, so action: FOO_BAR and stray keys fail early.

          jsonschema · api_schema.yaml
        

        

          
02

          
Parse

          
The spec is loaded into pydantic models: resources, attributes, transitions, enums, oneOfs and exceptions.

          KibaApi(**apiYaml)
        

        

          
03

          
Semantic check

          
Genie resolves routes and names, then rejects duplicate routes, operation-name clashes, reserved words, bad primary keys and invalid oneOfs.

          SemanticValidationException
        

        

          
04

          
Render

          
A target-specific language definition decides types, names and serialisation, and Jinja templates write the files.

          templates/<target>/*.j2
        

        

          
05

          
Diff-aware write

          
Only files whose content changed are rewritten, and files the spec no longer produces are removed. Your dev server only sees real changes.

          (1 files changed)
        

      

    


    

      

        
Naming is derived, not declared

        
Every transition becomes a route and two typed methods

        
Resource and action names decide the HTTP route, the abstract Python method you implement, and the client method you call. Both sides use the same rule, so a server and client generated from one spec always agree.

Type system

        
One type, two languages

        
Each spec type has a fixed rendering in each target. Nullable fields become | None in Python and | null in TypeScript, and dates are parsed and serialised for you.

      

      

        
String · Integer · Float · Boolean
str int float bool
string number boolean

        
Date · Datetime
datetime.date datetime.datetime
Date via dateFromString / dateToString

        
List
collections.abc.Sequence[T]
T[]

        
Mapping
collections.abc.Mapping[K, V]
Record<string, V>

        
Json
pydantic.JsonValue
JsonValue (recursive union)
For payloads you don't want to model, such as an LLM tool result or a third-party webhook body.

        
Enum
ReadingStatusV1 = typing.Literal['want-to-read', …]
type ReadingStatusV1 = 'want-to-read' | …
Named at the top level or inline with enumValues. The server rejects other values with a 400.

        
OneOf
Annotated[A | B, Field(discriminator='kind')]
A | B + xV1FromObject()
Each member is a resource with a single-value enum discriminator.

        
File
UploadedFile(filename, contentType, content)
File sent as multipart/form-data
POST only. The other fields go in the same form.

      

    


    

      

        
The details

        
The edge cases are covered too

      

      

        

          
Streams

          
responseType: stream gives an async generator on the server, sent as application/x-ndjson. The client gets a callback per item.

        

        

          
Partial updates that mean it

          
UPDATE fields are UpdateValue[T] = UNDEFINED, so "not sent" and "set to null" stay different from the client all the way to your code.

        

        

          
Renames fail type-checking

          
Internal methods take keyword-only parameters. Rename a parameter in your implementation and mypy reports an incompatible override.

        

        

          
Auth per transition

          
defaultAuthentication plus a per-transition authentication. Routes call your RouteAuthResolver with the policy name; none makes a route public.

        

        

          
Redirects and webhooks

          
responseType: redirect returns a location the server answers with a 302. source: query-parameters collects every query parameter for third-party callbacks.

        

        

          
Versioned by design

          
Each major version writes its own package, e.g. bookshelf_api/v1, and every class carries the suffix (BookV1), so two versions can be served side by side.

        

      

    


    

      

        
Watch mode

        
Edit the spec while the app is running

        
geniespec watch builds once, starts your command, rebuilds on every save and passes your command's exit code through. If the spec is invalid it keeps the last good output.
